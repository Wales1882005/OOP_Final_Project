## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Wales1882005/Wai_Phone_Thaw-OOP-.git
   ```
2. Navigate to a week's folder, e.g.:
   ```bash
   cd week_1
   ```
3. Compile and run any Java file:
   ```bash
   javac FileName.java
   java FileName
   ```
